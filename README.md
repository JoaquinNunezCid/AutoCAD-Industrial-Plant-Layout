# Vitroconvector Manufacturing Plant Layout
### AutoCAD · Academic Mechatronics Engineering Project

A 2D layout proposal for a vitroconvector manufacturing facility. The project focuses on functional space allocation, production flow, storage, receiving and shipping, staff facilities, and site circulation.

> **Project status:** Academic design proposal. The facility is not represented as built or operational.

## Design Basis

| Parameter | Value | Interpretation |
|---|---:|---|
| Reference annual market | 130,000 units | Planning assumption used in the coursework |
| Target market share | 5% | Project objective |
| Derived annual production target | **6,500 units/year** | 130,000 × 0.05 |
| Site area discussed during planning | Approximately 5,000 m² | Initial planning brief; not reconciled with the dimensioned site plan yet |

**Area verification note:** the supplied site-plan PDF shows outer dimension labels of 70,000 mm and 45,000 mm. If those dimensions define the full site boundary, the implied area is 70 m × 45 m = **3,150 m²**, which differs from the 5,000 m² planning assumption. The editable `.DWG` was not supplied, so this discrepancy cannot be resolved from the current files. Treat the site area as provisional until the dimensions are checked in the source drawing.

The 6,500-unit annual figure is a target derived from the assumed market size and 5% share; it is not a verified production result.

## Design Scope

The proposed process sequence includes raw-material storage, cutting, folding, perforating, surface preparation, painting, drying and staging, mechanical and electrical assembly, quality control and testing, packaging, order preparation, and finished-goods storage. The layout also represents receiving and shipping docks, personnel facilities, administration, and circulation.

## Source Files and Limitations

The repository contains presentation PDFs, PDF previews, original PDF exports, and the source items that were available. The supplied AutoCAD files included a `.BAK` backup and a `.DWT` template; an editable `.DWG` was not included. Those files are preserved in `source-files/` but are not claimed as substitutes for a verified editable drawing.

This repository documents academic CAD work. It does not claim structural calculations, regulatory approval, construction, or operational validation.
