## Project Scope

The proposed layout organizes production areas, raw-material and finished-goods storage, receiving and shipping docks, logistics circulation, staff facilities, and reception. The ground-floor production sequence includes cutting, folding, perforating, surface preparation, painting, drying/staging, mechanical and electrical assembly, quality control, packaging, and order preparation.

## Design Basis

- **Reference production capacity:** approximately 14,400 units per year.
- **Software:** AutoCAD.
- **Project type:** academic design proposal.

The production figure is a planning reference used for coursework. The facility is a proposal and is not represented as built or operational.

## Source and Limitations

The presentation PDFs use landscape A3 pages with titles and footers. They preserve the plan geometry and dimensions visible in the source PDFs; this presentation work does not constitute engineering validation or regulatory approval.

The materials supplied for this portfolio included the three PDF exports, an AutoCAD backup (.BAK), and a drawing template (.DWT). An editable .DWG was not included, so this repository does not claim to contain an editable DWG.
